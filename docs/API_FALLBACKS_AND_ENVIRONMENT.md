# Travel OS · API 연동 환경변수 및 오프라인/오류 폴백 정책 가이드

본 문서는 Travel OS의 실제 API 연동 시 필요한 환경 변수 목록, 공급자 API 키 부재 시의 안전 폴백 정책, 권한 거절 및 네트워크 오류 대응 체계를 정리한 공식 기술 명세서입니다.

---

## 1. 환경 변수 명세 (.env.local)

| 환경 변수명 | 대상 기능 | 선택/필수 | 설명 | 키 부재 시 폴백 동작 |
|---|---|---|---|---|
| `GEMINI_API_KEY` | 텍스트 번역 (`/api/translate`), 사진 메뉴 OCR (`/api/camera/translate`) | 선택 | Google Gemini 1.5 Flash 모델 API 키 | **정직한 503 반환**: 임의 번역 조작 없이 144개 검증 추천 여행 문구 제공. 메뉴 OCR의 경우 국가별 authentic 정적 샘플 데이터 분기 및 SAMPLE 배지 명시 |
| `GOOGLE_MAPS_API_KEY` | 지도 장소 검색 (`/api/places/search`) | 선택 | Google Places TextSearch API 키 | **OpenStreetMap Nominatim 실시간 지오코딩**(초당 1회 스로틀링 준수) 및 국가별 140+ 로컬 검증 장소 데이터베이스로 자동 폴백 |
| `NEXT_PUBLIC_APP_URL` | PWA 메타데이터 / 공유 링크 | 선택 | 웹 배포 도메인 베이스 URL | `window.location.origin` 자동 감지 |

> **안전 가이드라인:** 오너 승인 없는 신규 유료 API 서비스 계약 및 결제 등록은 엄격히 금지됩니다. 모든 기능은 API 키가 없는 로컬/무료 환경에서도 핵심 플로우(지도, 상황별 번역, 환율 계산기, 지갑)가 정상 동작하도록 설계되어 있습니다.

## 2. 기능별 오류 및 폴백 아키텍처

### 2.1 지도 및 장소 검색 (`/api/places/search`)
1. **Google Maps API 키 존재 시:** Google Places TextSearch API 호출 (`language=ko`).
2. **Google Maps API 키 부재 시:**
   - OpenStreetMap Nominatim 실시간 검색 (사용자 명시적 검색 시, 1시간 서버 캐시 + 초당 1회 레이트 리미트 준수).
   - Nominatim 네트워크 지연 또는 실패 시: 국가별 카테고리 로컬 데이터(`src/data/countries.ts`) 140여 건 즉시 반환.
3. **사용자 UI 고지:**
   - 데모/로컬 모드 시 상단에 `[데모 모드]` 배지 및 OpenStreetMap 실지형 타일 사용 고지.
   - 텍스트 말줄임(`truncate`) 없이 모바일 뷰에서도 명확하게 읽히도록 표시.

### 2.2 텍스트 번역 (`/api/translate`)
1. **검증된 여행 표현 매칭:** 사용자 입력이 상황별 핵심 표현(144건)과 일치(구두점/대소문자 정규화)하는 경우 즉시 검증된 번역 및 발음(로마자 표기) 반환.
2. **자유 문장 번역:**
   - `GEMINI_API_KEY` 설정 시 Gemini 1.5 Flash를 통해 실시간 번역 및 자연스러운 한국어 발음 가이드 생성.
   - 키 부재 또는 네트워크 오류 시: 가짜 번역(예: "(日本語訳)" 또는 엉터리 영어 조합)을 절대 생성하지 않고, **503 TRANSLATION_SERVICE_UNAVAILABLE** 오류와 함께 입력 상황과 가장 연관된 검증 추천 문구 3건을 제안.

### 2.3 양방향 음성 대화 (`VoiceChatModal.tsx`)
1. **브라우저 Web Speech API (STT / TTS):**
   - 크롬/사파리 모바일 웹 브라우저 내장 음성 엔진 활용 (추가 서버 비용 0원).
   - 한국어(`ko-KR`), 일본어(`ja-JP`), 영어(`en-US`), 대만(`zh-TW`), 베트남(`vi-VN`), 태국(`th-TH`) 등 BCP-47 표준 로케일 매핑.
2. **마이크 권한 거절 / STT 미지원 브라우저:**
   - `voice.permission.denied` 안내 및 직접 텍스트 입력창(`voice.action.type_instead`) 즉시 노출.
   - 사용자가 텍스트로 질문을 입력하여 양방향 번역 대화를 끊김 없이 이어갈 수 있도록 폴백 지원.
3. **번역 실패 시 TTS 안전 차단:**
   - 번역이 실패한 원문을 상대방 언어로 오독하지 않도록 음성 합성을 차단하고 재시도 옵션 제공.

### 2.4 카메라 메뉴 촬영 및 OCR (`CameraMenuModal.tsx`)
1. **실제 촬영 / 이미지 업로드:**
   - 10MB 초과 이미지 클라이언트 단에서 사전 차단 (`camera.error.too_large`).
   - 업로드 UI에 외부 서버 분석 및 전송 고지 (`camera.privacy.notice`) 명시.
2. **Gemini 비전 분석:**
   - 메뉴판 내 메뉴명, 설명, 현지 통화 가격, 신뢰도 추출.
   - `GEMINI_API_KEY` 부재 시: 정적 데모 메뉴 데이터(일본 라멘/교자, 미국 버거/커피, 베트남 쌀국수/반미 등)로 안전 폴백하며 `[SAMPLE]` 배지 및 샘플 안내를 명시.
3. **환율 및 지갑 연동 안전성:**
   - 메뉴 가격에서 인식된 통화와 여행 설정 통화가 불일치하거나 유효 환율이 없으면 `estimatedKrw: null`로 안전 격리 (0원이나 임의 환율 대입 금지).
   - 샘플 데이터의 지갑 저장은 실제 지출 여부를 사용자에게 재확인.

### 2.5 환율 정보 (`/api/rates` & `CurrencyView.tsx`)
1. **실시간 환율 API:** 무료 공공 환율 엔드포인트 연동.
2. **오프라인 / 네트워크 두절:**
   - 로컬 스토리지에 캐시된 최신 환율(최대 7일 유효) 적용 및 `isStale: true` (최근 캐시 환율) 표시.
   - 유효 캐시가 전혀 없는 경우 환율 미산정 상태로 표시하며 허위 1:1 환산 방지.

## 3. 모바일 터치 및 접근성 규격

1. **최소 터치 영역:** 모바일 인터랙션 요소는 최소 44px × 44px 터치 영역을 보장 (`min-w-[44px] min-h-[44px]`).
2. **시트 UX 계층:**
   - `peek` 모드: 지도 뷰를 최대한 확보하면서 2개 핵심 CTA(길찾기 + 이 장소에서 쓸 말) 우선 노출.
   - `expanded` 모드: 영업시간, 설명, 환율, 지갑, 메뉴 OCR 등 전체 도구 스크롤 지원.
3. **부동 지도 컨트롤 정합성:**
   - 장소 시트가 열릴 때 줌 인/아웃 및 내 위치 버튼이 시트 위로 부드럽게 상승하여 조작 간섭 차단.
